🔗 ฐานข้อมูลกลาง (Supabase)

ถ้ายังไม่เชื่อมต่อ เว็บจะทำงานใน “โหมดสาธิต” ข้อมูลอยู่ในเบราว์เซอร์เครื่องนี้เท่านั้น และไม่ส่งแจ้งเตือน Discord

ยังไม่ได้เชื่อมต่อ

ⓘ ค่าเชื่อมต่อถูกกำหนดไว้ใน CONFIG ในโค้ดแล้ว ทุกคนที่เปิดเว็บใช้ฐานข้อมูลเดียวกัน

✨ ข้อมูลตัวอย่าง (เฉพาะโหมดสาธิต)

เติมตารางเรียนและกิจกรรมตัวอย่างในสัปดาห์นี้ เพื่อดูหน้าตาตาราง

🛠️ วิธีตั้งค่า (ครั้งเดียว)

  1. สมัคร/ล็อกอิน supabase.com → New project
  2. SQL Editor → New query → วางโค้ดจากไฟล์ supabase-setup.sql → Run
  3. Project Settings → API คัดลอก Project URL และ anon key มาใส่ช่องด้านซ้าย หรือใส่ใน CONFIG บนสุดของ <script> ก่อน deploy เพื่อให้ทุกคนใช้ฐานข้อมูลเดียวกัน
  4. Discord: ห้องประกาศ → Edit Channel → Integrations → Webhooks → New Webhook → Copy URL
  5. กลับไปที่ SQL Editor รันคำสั่งนี้ (เปลี่ยน URL เป็นของคุณ) แล้วทุกการแก้ไขจะเด้งเข้า Discord ทันที: 
    insert into app_secret(key, value) values
  ('discord_webhook', 'https://discord.com/api/webhooks/…')
on conflict (key) do update set value = excluded.value;

🔒 Webhook เก็บในฐานข้อมูลส่วนที่หน้าเว็บอ่านไม่ได้ คนเปิดเว็บจึงเอาไปสแปมห้องไม่ได้ · การ “ลบ” เป็นการซ่อน กู้คืนได้จากประวัติเสมอ
