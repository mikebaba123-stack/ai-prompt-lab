# ข้อ 3 · กฎการทำความสะอาดและการรวมข้อมูลจาก 2 แหล่ง

> **สถานะ:** เครื่องมือเขียนและทดสอบเรียบร้อยแล้ว (`merge_sources.py`) — รอไฟล์แหล่งที่ 2 เท่านั้น
> เซสชันนี้เปิด kaggle.com ไม่ได้ (network policy บล็อก ได้ HTTP 000) จึงดาวน์โหลดแทนไม่ได้

## พรอมป์ที่ใช้ถาม AI

```
ฉันมีข้อมูล 2 แหล่งที่จะรวมกัน
แหล่งที่ 1: แบบสอบถามการใช้โซเชียลมีเดีย 150 คน (Age, Gender, Education_Level,
            เวลาใช้งาน 4 แพลตฟอร์ม, Usage_Period, Emotion, Sleep_Quality)
แหล่งที่ 2: ชุดข้อมูลจาก Kaggle เรื่องการใช้โซเชียลมีเดีย (ชื่อคอลัมน์คนละแบบ)
ช่วยกำหนด "ขอบเขตการทำความสะอาด" และ "กฎการรวม" ให้ชัดเจน
ต้องตัดสินใจอะไรบ้างก่อนรวม และจะรู้ได้อย่างไรว่ารวมถูกต้อง
```

## กฎที่ AI แนะนำ

### ก. ตัดสินใจก่อนลงมือ 3 ข้อ

| คำถาม | ทางเลือก | เลือกอะไรและทำไม |
|---|---|---|
| **สองแหล่งนี้เป็น "คนกลุ่มเดียวกัน" หรือ "คนละกลุ่ม"?** | join (ต่อคอลัมน์) / concat (ต่อแถว) | ถ้าเป็นผู้ตอบคนละชุด ไม่มีรหัสประจำตัวร่วมกัน → ต้องใช้ **concat ต่อแถว** เท่านั้น การ join มั่ว ๆ ด้วยอายุ/เพศจะจับคู่คนละคนเข้าด้วยกัน = ข้อมูลผิดทั้งชุด |
| **หน่วยข้อมูลตรงกันไหม?** | ชั่วโมง/นาที/ต่อวัน/ต่อสัปดาห์ | แปลงให้เป็น **ชั่วโมงต่อวัน** ให้หมดก่อนรวม มิฉะนั้นค่าเฉลี่ยจะไม่มีความหมาย |
| **ต้องการทุกแถวหรือเฉพาะที่ครบ?** | outer / inner | งานสำรวจควรใช้ **outer (เก็บทุกแถว)** แล้วทำเครื่องหมายว่าค่ามาจากแหล่งไหน |

### ข. กฎทำความสะอาดที่ใช้กับ *ทุก* แหล่ง (ก่อนรวม)

1. **ทำชื่อคอลัมน์ให้เป็นมาตรฐานเดียว** — `Avg_Daily_Usage_Hours`, `Daily_Hours`, `Total_Time_Hours` → `daily_hours` (สคริปต์มีพจนานุกรมจับคู่ให้แล้ว) และถ้าจับคู่แล้วชนกัน ให้เติมเลขต่อท้ายแทนการทับกัน
2. **ค่าว่างเป็นมาตรฐานเดียว** — `""`, `" "`, `NA`, `missing`, `None`, `-`, `?` → NaN
3. **บังคับชนิดข้อมูล** — คอลัมน์ที่ชื่อมี age/hour/time/score/year → ตัวเลข (ถ้าแปลงได้เกินครึ่ง)
4. **รวมค่าหมวดหมู่** — Female/femail/F/woman → `Female` · ข้อความอื่นทำเป็น Title Case
5. **ตัดแถวซ้ำภายในแหล่งเดียวกันก่อน** แล้วค่อยตัดซ้ำอีกครั้งหลังรวม
6. **ติดป้ายที่มา** — เพิ่มคอลัมน์ `source_file` ทุกแถว เพื่อให้ย้อนได้ว่าข้อมูลมาจากไฟล์ไหน

### ค. กฎการรวม

7. **รวมด้วย concat + จับคู่ชื่อคอลัมน์** — คอลัมน์ที่มีเฉพาะบางแหล่งจะเป็นค่าว่างในแถวของอีกแหล่ง ซึ่ง **ถูกต้อง** ไม่ใช่ข้อผิดพลาด ห้ามเติมมั่ว
8. **ห้าม join ด้วยคอลัมน์ที่ไม่ใช่รหัสเฉพาะ** (อายุ เพศ ประเทศ) เพราะจะเกิด cartesian explosion — ถ้าจำเป็นต้อง join จริง ให้ join กับ *ตารางอ้างอิง* (เช่น ตารางแพลตฟอร์ม) ที่มี 1 แถวต่อ 1 คีย์เท่านั้น
9. **ตรวจหลังรวม 4 อย่าง** — (ก) จำนวนแถวรวม = ผลบวกของทุกแหล่ง ลบแถวซ้ำ · (ข) ไม่มีคอลัมน์ที่ค่าว่าง 100% · (ค) ช่วงค่าของคอลัมน์ตัวเลขยังสมเหตุสมผล · (ง) จำนวนค่าไม่ซ้ำของคอลัมน์หมวดหมู่ไม่ระเบิด (ถ้าเพศมี 7 ค่า แปลว่ากฎข้อ 4 ยังไม่ครบ)

## วิธีรัน (เมื่อมีไฟล์แหล่งที่ 2 แล้ว)

```bash
python merge_sources.py Social_Media_Usage_Survey_raw.csv kaggle_dataset.csv
# หรือถ้ามีคอลัมน์รหัสร่วมกันจริง ๆ
python merge_sources.py file1.csv file2.csv --how join --key user_id
```

ได้ไฟล์ออกมา 3 อย่าง ซึ่งตรงกับที่โจทย์ขอพอดี

| ไฟล์ | ใช้ส่งเป็น |
|---|---|
| `source_profile.md` | **ต้นฉบับของ data** — ตารางคอลัมน์ ชนิดข้อมูล ตัวอย่างค่า ค่าว่าง ของทุกแหล่ง + 5 แถวแรก |
| `merged_dataset.csv` | **ผลลัพธ์ของการรวม data** |
| `merge_report.md` | หลักฐานว่ารวมถูกต้อง — จับคู่คอลัมน์อย่างไร แถวก่อน/หลัง คอลัมน์ร่วม/ไม่ร่วม ค่าว่างต่อคอลัมน์ |

| insight | ตัวเลข |
|---|---|
| แพลตฟอร์มที่กินเวลามากที่สุด | **TikTok 462.4 ชม.รวม** (Facebook 417.0 · YouTube 361.8 · Instagram 329.4) |
