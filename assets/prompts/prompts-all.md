## แง่ที่ 1 · สร้างรูปด้วย AI (Canva / Text-to-Image)

**พรอมป์แรก — Zero-shot**
```text
สร้างรูปเกี่ยวกับปัญญาประดิษฐ์
```

**พรอมป์ใหม่ — Few-shot / เพิ่มรายละเอียด**
```text
สร้างภาพประกอบสไตล์ isometric 3D สะอาดตา หัวข้อ "AI ช่วยมนุษย์เรียนรู้"
# ประธานของภาพ
นักศึกษานั่งทำงานคู่กับผู้ช่วย AI ที่เป็นสมองดิจิทัลเรืองแสง
# องค์ประกอบ
โหนดโครงข่ายประสาทเชื่อมกันด้วยเส้นข้อมูล, ไอคอนหนังสือและกราฟลอยรอบตัว
# โทนสี
ส้มเบิร์นต์ (#D9480F) ตัดกับน้ำเงินปิโตรล (#1E5566) บนพื้นครีม (#F7F3EA)
# แสงและอารมณ์
แสงนุ่ม มีเงาบาง ๆ ให้ดูมีมิติ — โทนทันสมัย เป็นมิตร น่าเชื่อถือ
# สัดส่วน
16:9 เว้นที่ว่างด้านบนสำหรับใส่หัวข้อ
# ไม่เอา (negative)
ตัวอักษรมั่ว, ลายน้ำ, ใบหน้าบิดเบี้ยว, สีฉูดฉาดเกินจริง
```

## แง่ที่ 2 · กราฟความสัมพันธ์ทางคณิตศาสตร์ (Desmos)

**พรอมป์แรก — Zero-shot**
```text
วาดกราฟของ AI ใน Desmos
```

**พรอมป์ใหม่ — Few-shot**
```text
ฉันต้องการอธิบาย "ฟังก์ชันกระตุ้น (activation function)"
ในโครงข่ายประสาทเทียม ช่วยให้สมการและการตั้งค่าเพื่อพล็อต
เปรียบเทียบ 3 ฟังก์ชันในกราฟเดียว:
1) Sigmoid : f(x) = 1 / (1 + e^(-x))
2) Tanh    : g(x) = (e^x - e^(-x)) / (e^x + e^(-x))
3) ReLU    : h(x) = max(0, x)
- ตั้งช่วงแกน x: -6 ถึง 6 , แกน y: -1.2 ถึง 3
- ใส่สีต่างกันและ label กำกับแต่ละเส้น
- อธิบายสั้น ๆ ว่าทำไม sigmoid/tanh "อิ่มตัว" ส่วน ReLU เป็นเส้นตรงครึ่งซีก
```

## แง่ที่ 3 · ไดอะแกรมจาก Mermaid

**พรอมป์แรก — Zero-shot**
```text
ทำ flowchart เกี่ยวกับ AI ให้หน่อย
```

**พรอมป์ใหม่ — Few-shot**
```text
เขียนโค้ด Mermaid เป็น flowchart แนวตั้ง อธิบาย
"วงจรการพัฒนาโมเดล Machine Learning" ให้มีขั้นตอน:
เก็บข้อมูล → ทำความสะอาด → แบ่ง Train/Test → เทรนโมเดล
→ มีจุดตัดสินใจ "ความแม่นยำพอหรือยัง?"
   - ถ้าไม่พอ ให้วนกลับไปปรับ hyperparameter/เพิ่มข้อมูล
   - ถ้าพอ ให้ไป Deploy แล้วเก็บ feedback วนกลับมาต้นทาง
ใช้ภาษาไทยในทุก node และจัดให้อ่านง่าย
```

## แง่ที่ 4 · บทความจาก LaTeX (Overleaf)

**พรอมป์แรก — Zero-shot**
```text
เขียนบทความ LaTeX เรื่อง AI
```

**พรอมป์ใหม่ — Few-shot**
```text
เขียนบทความวิชาการภาษาไทยด้วย LaTeX (คอมไพล์ด้วย XeLaTeX)
หัวข้อ "นิวรอนเทียมและการเรียนรู้ของเครื่อง" ให้มี:
- title, author, บทคัดย่อ (abstract)
- 3 หัวข้อ: บทนำ / โมเดลนิวรอน / การเรียนรู้
- สมการผลลัพธ์ของนิวรอน (sigmoid) และสมการ loss (cross-entropy)
  แบบ numbered equation
- ตั้งค่าฟอนต์ไทยด้วย fontspec และรายการอ้างอิง 2 รายการ
ส่งเป็นไฟล์ .tex ที่พร้อมวางใน Overleaf
```

## แง่ที่ 5 · สไลด์สรุปด้วย NotebookLM

**พรอมป์แรก — Zero-shot**
```text
สรุปเรื่อง AI เป็นสไลด์
```

**พรอมป์ใหม่ — Few-shot**
```text
สร้างสไลด์สรุปเรื่อง "ปัญญาประดิษฐ์เบื้องต้น"
- ผู้ฟัง: เพื่อนร่วมชั้นวิชา GE931 (ไม่ใช่สายเทคนิค)
- จำนวน: 6 สไลด์ พอดีนำเสนอ 5 นาที
- แต่ละสไลด์ให้มี: หัวข้อ + 3 bullet สั้น + 1 โน้ตผู้พูด
- ลำดับ: AI คืออะไร → ประเภท → ML ทำงานยังไง
  → ใช้จริงที่ไหน → ข้อควรระวัง/จริยธรรม → สรุป+อนาคต
- ใช้ภาษาเข้าใจง่าย มีตัวอย่างใกล้ตัว
```

## แง่ที่ 6 · เว็บไซต์บน GitHub Pages

**พรอมป์แรก — Zero-shot**
```text
ทำเว็บเกี่ยวกับ AI
```

**พรอมป์ใหม่ — Few-shot**
```text
สร้างเว็บไซต์หน้าเดียว (index.html) ภาษาไทย หัวข้อ "ปัญญาประดิษฐ์"
เพื่อ deploy บน GitHub Pages โดย:
- รวมผลงาน 6 แง่ (รูป AI, กราฟ Desmos, ไดอะแกรม Mermaid,
  บทความ LaTeX, สไลด์สรุป, ตัวเว็บเอง) ให้ต่อเนื่องเป็นเรื่องเดียว
- แต่ละแง่แสดง 5 ขั้น: พรอมป์แรก → ผล → พรอมป์ใหม่ → ผล → บทสะท้อน
- ดีไซน์ธีม "สมุดบันทึกการทดลอง" มีสารบัญ, สลับโหมดสว่าง/มืด
- ฝัง Mermaid และสมการ (MathJax) ให้เรนเดอร์ในหน้าได้จริง
- responsive รองรับมือถือ และเป็นไฟล์เดียวจบ ไม่พึ่งไฟล์ภายนอก
```

## สรุปสิ่งที่ "เพิ่มเข้าไป" เมื่อเปลี่ยนจาก zero-shot เป็น few-shot

| หลักการ | สิ่งที่เติมลงในพรอมป์ |
|---|---|
| บริบท (Context) | ใครใช้ ใช้ทำอะไร ในวิชา/สถานการณ์ไหน |
| เจาะจง (Specificity) | ประธานของภาพ ชื่อฟังก์ชัน ขั้นตอน ชื่อหัวข้อ |
| รูปแบบผลลัพธ์ (Format) | 6 สไลด์, flowchart แนวตั้ง, ไฟล์ .tex, สมการเลขที่ |
| ตัวอย่าง + ข้อจำกัด | ตัวอย่างสมการ/โครงสไลด์ และ negative prompt |
| ทำซ้ำและปรับ (Iterate) | ดูผลครั้งแรกแล้วเติมสิ่งที่ขาด |
